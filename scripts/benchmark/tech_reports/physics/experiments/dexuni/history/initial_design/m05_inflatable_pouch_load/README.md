# M05 夹取充气软包放到桌面，再放刚体块压载｜中等｜P1

**耦合配置**：基准组使用双向 `two_way` + 动态关节 `dynamic`；属于预计低风险配置，尚未实测确认，细网格/并行扩展另评估。

**目的**：先完成可变形充气包装的抓取放置，再观察刚体压载下的几何变化与承托结果。原不同材料条带拉伸任务从主矩阵移除。

**场景**：W1 V030 + 双 Pika。采用超市装袋示例的闭合 `pouch_mesh()`，参考未变形包络约 66×92×34 mm，作为独立充气薄膜物体 P；不能以实心软体方块冒充充气包。右侧初始区中心约 `(0.43,-0.22)`，桌面目标中心 `(0.52,0)`；左侧备有刚块 G，初始中心约 `(0.40,+0.22,0.02)`。摆放高度按闭合网格实际最低点确定。

充气采用公开 `ClothPhysicsDesc(pneumatic=PneumaticPhysicsDesc(...))` 创建。参考示例为 `ISOTHERMAL`、`reference_absolute_pressure=101800 Pa`、`ambient_pressure=101325 Pa`、`bulk_damping=10`、`max_absolute_pressure=180000 Pa`；膜材料参考 `tri_ke=tri_ka=20000、tri_kd=1、edge_ke=0.015、edge_kd=0.002、surface_density=0.18`。这些是配置输入而非当前内压读数。闭合拓扑、朝向与初始鼓起形状须一起保留，不能直接把开口布片加压力参数当软包。

**动作**：右臂夹软包→提起→移到目标桌面→降低、松爪并退开→静置 1 s 建立未压载参考→左臂夹刚块→置于软包中央→缓慢降低、松爪并退开→观察 2 s。两臂顺序操作，避免同一狭窄区域同时进手；约 20–25 s。不在任务中调节气压来迎合压载结果。

**测量**：软包抓取提起高度、放置中心误差；压载前后软包整体高度 `max(z)-min(z)`、预先定义的中央上表面节点组平均高度变化；刚块几何中心轨迹和最低点高度；压载后 1 s 的刚块 XY 漂移。数据为软包 `get_particle_positions()`、刚块 `get_world_pose()`、机器人指尖位姿。整体包络高度可能因侧向鼓起增加，不能直接将其下降解释为中央压缩，故中央标记组单列。

**建议成功线**：软包先独立完成提起与桌面放置，几何中心目标误差建议≤20 mm；刚块放置后保持在软包投影中央区域且未滚落。记录刚块底面相对桌面高度和软包中央高度：如果刚块已经压到底、由桌面直接支撑，必须标为压到底，不能称为软包独立承托。参考 50 g 刚块，若其载荷导致不可执行结果，先做独立载荷 pilot 冻结质量后重启正式矩阵，不能在正式运行中临时改气压或质量。

**读数边界**：没有采用公开实时内压、漏气率或接触力读数；本任务不报告这三项。现有示例已创建同类充气软包并用节点位置作过程检查，但目标 W1/Pika 双向动态驱动与压载步骤仍未运行验证。
