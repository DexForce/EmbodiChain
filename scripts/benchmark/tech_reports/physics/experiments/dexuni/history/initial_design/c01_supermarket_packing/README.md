# C01 超市混合装袋：刚体、软体和充气软包｜复杂｜P0，主展示场景

**耦合配置**：基准组使用单向 `one_way`；夹爪开口按几何预设并冻结，优先运动学回放。多层/多物体配置先控制反馈成本；此组不报告机器人受载反馈或限力闭爪平衡。

**目的**：参考 `demo_dexuni_supermarket_packing.py`，依次夹取刚体商品、体积软体商品、充气软包并放入同一个塑料购物袋，展示三类商品与薄膜袋同场景共同接触。取消原布兜搬运方案。

**场景**：W1 V030 + 双 Pika，工作台划分左侧刚体输入区、右侧软体/软包输入区与中部装袋区。塑料袋沿用参考资产 `shopping_bag.json` 的薄膜网格与真实挂架碰撞支撑方式，袋子不 pin 到世界或机器人；袋口由明确建模的挂架支撑，挂架和袋把手初态同时冻结。保留原袋尺寸和拓扑，先在该资产上确认三件商品能装下，再做整体布局刚体变换以适配 W1；不能只扩大视觉袋口。

商品包括：刚块 G；参考 `bread.npz` 的体积软体商品（密度 250 kg/m³、`k_mu=15000、k_lambda=30000、k_damp=1` 为示例起点）；M05 的闭合充气软包 P。刚体输入中心约 `(0.40,+0.23)`，软体/软包分别在 `(0.40,-0.23)`、`(0.60,-0.23)`，袋口工作中心约 `(0.52,0)`。装袋区采用明确建模的台面缺口或相邻悬挂工位，使袋体可以低于操作台面；缺口范围由冻结袋体和挂架包络外扩至少 20 mm 确定，不能把悬挂袋放进完整桌面碰撞体中。三个输入占位与袋/挂架/缺口不得重叠，实际物体初始高度、袋口高度和装入深度从冻结资产确定；所有抓取部位必须落在 Pika 实际开口范围内。

**动作**：左臂抓刚体→提起→越过袋口并降低→松爪、退开；右臂依次对软体和充气软包重复相同阶段。每件释放后观察 1 s，全部入袋后静置 2 s；约 36–45 s。两臂不同时伸入袋口，刚块先放底部、可变形商品后放，降低挤压和阻塞。主任务只装袋，不增加提袋或双臂交接。

**测量**：三件商品各自的抓取/离台/运输/释放标记、实际提起高度、松爪时几何中心与袋口标记组的相对位置、最终几何中心轨迹及袋底/袋口标记高度；刚体使用变换后的固定几何顶点，软体/软包使用粒子坐标。记录一件、两件、三件全部留存的结果，不只报告最终二进制成功率。

**建议成功线**：每件商品确实离开输入台面、完成向袋内移动并脱离夹爪。全部释放 2 s 后，三件几何中心位于冻结的袋口投影判定区内、低于袋口标记组且高于袋底标记组附近，且无明显继续下落。该区域判据与视频共同判断是否装入，不能证明商品表面完整包含或袋壁零穿透；穿袋/袋外滞留单独记录，不能用中心包含掩盖可见漏出。

**与参考实现的边界**：现有超市示例是 Piper 运动学控制，操作对象为体积软体 bread 与充气 pouch；货架装饰不等于已验证刚体抓取。本文新增刚体 G，迁移到 W1/Pika 的单向轨迹回放主组后必须重新验证预设夹爪开口、三件抓取、入袋路径与整体稳定性；若后续增加双向组，另列配置与结果，不直接引用原示例成功率。参考实现的 `PackingChecks` 已通过公开节点位置计算提起、几何中心与袋内近似判定，可复用其读数方法而非机器人轨迹或私有 IK 实现。
