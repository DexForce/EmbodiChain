# C02 左臂持袋口框、右臂装填软块与刚块｜复杂｜P1，应用展示场景

**耦合配置**：基准组使用单向 `one_way`；夹爪开口按几何预设并冻结，优先运动学回放。多层/多物体配置先控制反馈成本；此组不报告机器人受载反馈或限力闭爪平衡。

**目的**：检验薄壁容器、多物体共同接触、软体受载形变与双臂异步协作。

**场景**：开口布袋 F 底部位于 `(0.52,+0.02,0)`，底部由台面支撑。袋口缝接到一个净开口约 180×140 mm、圆角 5 mm 的轻质刚性框，框左侧有明确抓取柄，质量和惯量单独登记。左臂真实夹住该柄保持袋口，右臂从上方装填。软块 A 位于 `(0.40,-0.23,0.03)`，刚块 G 位于 `(0.60,-0.23,0.02)`。布与框之间的缝接属于公开的物理夹具连接，两平台必须使用等价连接；没有对应创建能力时此任务标为待适配，不能用隐形世界固定替代。

**动作**：左臂保持袋口框→右臂抓软块、经过袋口、释放→右臂抓刚块、放入软块上方→右臂夹住框另一侧抓取柄→双臂提起 80 mm→放下；约 30–40 s。框和布袋均为动态物体，不固定到世界。主任务使用明确的袋口框，避免把单点抓持柔软袋口的开口控制变成主要难点；无框软袋另作后续扩展。

**测量**：软块/刚块是否分别通过袋口和完成释放、提袋后的载荷高度、装填和提袋各阶段成功标记。

**建议成功线**：装填后两物体进入由动态袋口框定义的袋内判定区，提袋 1 s 不掉落。以袋框局部坐标和物体几何范围作实用判定，不能把包围区包含当成袋壁无穿透证明；缝接或任一关键读数不可用则标待适配。

**说明**：此场景借鉴已有装袋几何和流程，但目标机器人、Pika、动态控制和无 pin 条件需重新验证，不能直接引用旧 demo 成功率。
