# S04 双侧分别夹取刚块和软块：小变形夹持｜简单｜P0

**耦合配置**：基准组使用双向 `two_way` + 动态关节 `dynamic`；属于预计低风险配置，尚未实测确认，细网格/并行扩展另评估。

**目的**：直接参照现有 `demo_dexuni_w1_squeeze_grasp.py`，以简单夹取展示刚体阻挡、软体轻微压缩和动态双向响应。左右手各拿一个物体，不要求协同操作同一物体。

**场景**：W1 V030 + 双 Pika；左侧刚块尺寸 48×48×90 mm，中心 `(0.43,+0.25,0.045)`、密度 450 kg/m³；右侧软块尺寸 60×60×80 mm，中心 `(0.43,-0.25,0.042)`、密度 250 kg/m³。几何和位置先沿用示例，再按已确认夹爪 TCP 核验。

**动作**：双侧靠近→限力闭爪→同步提起 150 mm→保持约 2 s→降低→松爪；完整运行至少 720 帧、约 12 s。软块仅轻微压缩，不追求 S02 的大变形。

**测量**：左右手指实际关节位置、保持期手指位置峰峰值、两个物体提起高度、软块 Y 向包络宽度和释放后宽度恢复。这些数据已在现有示例的 `after_step()` 和 `test_final()` 使用。

**建议成功线**：两个物体均提起至少 120 mm，保持后释放回桌面；小变形档建议实际宽度压缩率 5%–15%。保持期每侧选定手指关节位置峰峰值≤0.5 mm可作为沿用示例的试跑起点。材料与限力预先选定，若实际变形超过该档，就按实际变形报告，不能只因动作简单称为小变形。

**复用边界**：现有示例初始软材料参数为 `k_mu=6e3、k_lambda=1.5e4、k_damp=1e-3`，它没有断言压缩率≤15%；该任务的小变形档仍需试跑冻结材料/限力。原示例的 0.5 mm 判据测的是单指关节位置，不是未经标定的总夹爪开口；更换 Pika 后不能直接用两倍关系换算。可增设 one-way 诊断组，但不把其结果并入 two-way 成功率。
