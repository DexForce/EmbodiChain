# 共享资产

机器人、夹爪、商品网格、购物袋和纹理由既有资产下载/缓存入口解析。此目录用于后续保存共享资产 manifest、哈希和生成说明，不复制用户资产目录，也不重复下载同一资产到十一个任务中。

各任务 `configs/` 引用同一冻结资产清单，manifest 中记录解析后的实际路径、来源版本与 SHA256。W1/Pika 与 Franka/Panda 分别校验装配、TCP、惯量和碰撞；原示例机器人或末端不能只改名称当作已迁移。详细资产依据见 [总计划](../PLAN.md)。当前尚未生成可运行资产包。
