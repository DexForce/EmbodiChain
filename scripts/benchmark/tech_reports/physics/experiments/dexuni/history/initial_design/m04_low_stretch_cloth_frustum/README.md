# M04 双臂持低延展布下压棱台平顶｜中等｜P0

**耦合配置**：基准组使用双向 `two_way` + 动态关节 `dynamic`；属于预计低风险配置，尚未实测确认，细网格/并行扩展另评估。

**目的**：双臂持低延展布料向下压棱台平顶，接触区域限定为顶面，观察顶面穿模风险及动态机器人—布料耦合响应。布料不沿斜面包覆。

**场景**：W1 V030 + 双 Pika。桌面固定一个正四棱台，中心 XY 为 `(0.48,0)`，底面 120×120 mm、平顶 40×40 mm、高 80 mm；不使用尖顶锥体。初版使用这些平面定义的凸碰撞网格，不能另用方盒近似碰撞。方布 D 在棱台旁取起后移到正上方，两臂夹住左右相对布边的中部；抓点约 `(0.48,±0.14)`，初始布边高于棱台平顶至少 40 mm。取布到预定位的过渡轨迹单独冻结。

**布料设置**：使用低延展的膜材料配置，保留柔性的弯曲表现；提高膜内拉伸/面积刚度不等于把弯曲刚度也提高成硬板。两者分别设置。以创建时固定的材料边和纵向节点线比较长度变化，试跑目标为有效受力区拉长约不超过 1%–2%；这是待验证的低延展目标，不是已经达到的精度。材料参数、网格、子步和驱动限值在正式运行前共同冻结，不能以大幅拉长布料换取目标下压位移。

**动作**：双臂持布到平顶上方并轻微张紧→缓慢下降到布中央接触顶面→保持抓点水平间距，分小步继续给出向下目标→保持 2 s→抬起卸载。抓点高度先从台面上约 120 mm降至 80 mm附近，再以每档约 5 mm的目标下降试跑，最低先限制在约 60 mm；取消内收抓点和下降至 40 mm的包覆路径。实际下压量由布料低延展性、驱动限值和夹持状态共同决定，不要求机器人强行达到目标；约 12–16 s。试跑检查未夹持布边的下垂，只有顶面接触且与斜面保持间隙的配置才进入本任务正式组，出现斜面接触需调整预张紧或缩小下降量后重新冻结配置。

**测量**：①布中央与边部材料标记高度；②抓取手指与腕部链接的实际高度及相对目标的误差；③平顶投影范围内布节点低于顶面的深度，以及棱台内部节点量；④有效受力区固定材料边/节点线相对初始长度的变化。数据来源为公开粒子坐标、`get_current_qpos()`、`get_link_pose()` 和创建时已知棱台几何；不声称读到实际压布力。平顶范围为 `abs(u)≤0.02、abs(v)≤0.02`，对应节点的顶面下穿量为 `max(0,0.08-h)`；必须同时注明节点采样范围和碰撞厚度。

**建议成功线**：在只接触顶面的条件下完成下压、保持和卸载，两个抓取区未滑脱，布料长度变化保持在冻结的低延展范围内。实际腕部/手指运动与目标差异如实记录，受阻而未达到下降目标不自动算任务失败。顶面下穿与棱台内部节点量报告实测值；是否通过质量线取决于事先冻结的几何容差，不预先承诺零穿透。斜面间隙通过公开节点/布网格与已知棱台侧面离线核验，该核验不是现成粒子接触 API；未完成前仅标试跑观察，不宣称已确认顶面独占接触。

**可直接算的几何量**：转换到棱台局部坐标 `(u,v,h)`，`0<h<0.08` 时半边宽 `b(h)=0.06-0.5*h`；若 `abs(u)<b(h)` 且 `abs(v)<b(h)`，节点位于实体内部。内部节点到最近边界面的距离为 `min(h,0.08-h,(b(h)-abs(u))/sqrt(1.25),(b(h)-abs(v))/sqrt(1.25))`；非内部节点记零。该公式对应未倒角正四棱台且与碰撞形状一致，实施时用已知内/外/表面点校验。它是节点下穿量，不会发现所有边/面穿越；完整布面穿模仍需单独的三角面检查。

**耦合边界**：棱台固定用于隔离接触质量，不能据此声称验证了动态棱台反作用；主观察对象是有动态关节的机器人与布料。后续若让棱台动态运动，另开配置和成功判据。
