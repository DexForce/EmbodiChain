# M02 双臂方布单次对折：两层接触｜中等｜P0

**耦合配置**：基准组使用双向 `two_way` + 动态关节 `dynamic`；属于预计低风险配置，尚未实测确认，细网格/并行扩展另评估。

**目的**：测试双点夹持、布料自碰撞和第一层间接触。

**场景**：方布 D 中心 `(0.48,0)`；两臂抓取近侧边两角 `(0.33,±0.15)`，目标折线 `x=0.48`，对齐远侧边 `x=0.63`。另一半保持自由。

**动作**：同步抓角→抬起 100–120 mm→越过折线→缓慢放下→松爪并观察 2 s；约 12 s。启用自碰撞，保持材料和摩擦恒定。

**测量**：固定材料角点/边中点的 XY 对齐误差、第二层是否落到第一层目标区域、动作完成率。对齐误差由创建时标记的材料节点组计算。

**建议成功线**：释放 2 s 后，移动侧两个角点组与目标侧对应组的 XY 距离均≤15 mm，折叠过程完整。两层来自单折流程；布面贯穿另列几何检查，不能由角点对齐推断。
