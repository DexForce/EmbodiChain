# M03 双臂直接夹取四层布料并定点放置｜中等｜P1

**耦合配置**：基准组使用单向 `one_way`；夹爪开口按几何预设并冻结，优先运动学回放。多层/多物体配置先控制反馈成本；此组不报告机器人受载反馈或限力闭爪平衡。

**目的**：直接测试多层布的夹持、搬运和层间滑动，取消机器人连续二次折叠与叠边重新抓取。

**场景**：W1 V030 + 双 Pika。四张独立的 300×300 mm 方布 D 预叠放，中心 XY 为 `(0.43,0)`，各层有独立 Scene 路径和节点 ID。每层密度/网格相同，总质量 72 g。初始层间距按碰撞厚度设置，预沉降后不得互相重叠；明确这是四张独立布的四层叠放，不称为单片布自碰撞折叠。

布叠放在有明确几何的低矮取料台上；取料台在两个抓取位置留出夹指通道，边缘支撑和伸出量一致，避免指尖先碰桌面导致夹不到底层。两臂夹住同一近侧边两端的四层叠边，抓点间距约 260 mm。目标区为桌面中心 `(0.58,0)` 的 340×340 mm 标记区；起终点允许部分投影重叠，以明确的四层位移判定是否搬运。

**动作**：夹紧四层→同步抬起，使最底层也离开取料台→保持 2 s→沿 +X 搬运 150 mm→降低至目标台面→松爪并退开→观察 2 s；约 14–18 s。不将各层粘接、焊接或共同 pin 到夹爪。

**测量**：每一层的最低节点高度、节点几何中心轨迹、保持期各层几何中心相对位移、释放后各层到目标中心的 XY 误差及目标区内节点比例。四层读数来自四个公开粒子句柄，可直接发现只夹起上面一两层的问题，不需要自动识别层数或层序。

**建议成功线**：四层最低节点均离开取料台≥50 mm并保持 2 s；四层都完成约 150 mm 位移。释放 2 s 后，每层几何中心距目标中心≤20 mm，至少 95% 节点投影在目标区内。漏抓、掉层与层间滑移分别记录，不能只看最上层视频判成功。
