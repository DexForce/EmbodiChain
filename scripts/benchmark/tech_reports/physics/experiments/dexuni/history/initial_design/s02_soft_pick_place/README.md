# S02 软块大变形抓取、提起与定点放置｜简单｜P0

**耦合配置**：基准组使用双向 `two_way` + 动态关节 `dynamic`；属于预计低风险配置，尚未实测确认，细网格/并行扩展另评估。

**目的**：观察大变形夹取，并完成有明确终点的搬运放置。

**场景**：Franka Panda + 标准二指夹爪。软块 A 初始中心 `(0.43,-0.12,0.03)`；目标区域中心 `(0.57,+0.08)`，尺寸 140×140 mm，固定目标中心与边界写入配置。目标区与初始软块投影不重叠，不能原地松爪算搬运。

**动作**：夹住物体中部→实际宽度压缩进入 30%–40% 档→提起 120 mm→保持 2 s→移动到目标区上方→缓慢降低到台面附近→开爪并退开→观察 2 s。放置前不能直接在空中释放；全程约 14–16 s。驱动预算不能达到该压缩档时保留实际值，不越限补偿。

**测量**：夹持宽度变化、最低节点离台高度、保持末段下降量、释放后节点几何中心到目标中心的 XY 距离、投影位于目标矩形内的节点比例，以及释放后的宽度恢复误差。最后两个位置量由全部粒子坐标直接计算，不需图像分割或软体质心接口。

**建议成功线**：最低节点离台≥80 mm并保持 2 s；末 1 s 下降≤10 mm。松爪 2 s 后几何中心距目标中心≤20 mm、至少 95% 节点投影在目标区内，且物体已回落到台面附近；位置有限。目标区节点比例是明确的几何判据，不宣称表面完整包含或无穿透。抓取、提起、运输、放置分阶段计成功率。
