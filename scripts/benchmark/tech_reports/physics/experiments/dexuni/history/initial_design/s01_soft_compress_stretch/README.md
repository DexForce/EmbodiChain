# S01 软体小变形压缩／拉伸与恢复｜简单｜P0

**耦合配置**：基准组使用双向 `two_way` + 动态关节 `dynamic`；属于预计低风险配置，尚未实测确认，细网格/并行扩展另评估。

**目的**：用两个独立子任务观察受压和受拉后的几何恢复；不把拉伸混入压缩 episode，也不增加应力或力学参数反演。

**场景**：Franka Panda + 标准二指夹爪。S01-C 压缩沿用软块 A，中心 `(0.48,-0.10,0.03)`，Franka 夹住压板 H 的抓取柄。S01-T 拉伸使用 120×40×40 mm 弹性长块，长轴沿 X、密度 250 kg/m³、质量 48 g，中心约 `(0.46,-0.10,0.06)`；近端由明确建模的桌面固定夹具夹紧，Franka 夹住远端。夹具是实际碰撞刚体，不是世界 pin 或将节点焊在机器人上，夹口几何、预夹紧量与摩擦在两平台相同。自由段预设两组材料标记，距两夹持区各留出间隔。

**动作**：压缩子任务：接触→实际高度压缩 5%/10%→保持 1 s→卸载→恢复 2 s。拉伸子任务：近端夹紧、远端抓住→缓慢沿 +X 拉伸→保持 1 s→回到初始端位并松爪→恢复 2 s。拉伸先做 5%，10% 为受载预算通过后的扩展；每个子任务约 8–12 s。不能单手把自由软块拖动当成拉伸。

**测量**：压缩率取 `1-h/h0`；拉伸率取自由段纵向材料线长度 `L/L0-1`，材料线由固定节点 ID 的相邻三维距离求和，避免整体位移或拉直影响。另记录两端材料标记相对夹具/指尖的漂移、卸载 2 s 后的高度或长度恢复误差，及桌面内节点下穿量。数据为 `get_particle_positions()`、`get_link_pose()` 和固定夹具变换。

**建议成功线**：压缩/拉伸分别达到冻结的目标±2 个百分点；恢复误差先以基准长度/高度的 5% 为试跑起点。拉伸端部漂移建议≤3 mm；超出记为夹持滑移，不将其作为材料恢复或伸长结果。固定夹具未建立可靠夹持前，S01-T 标待验证，不以隐式附着补齐。只报告几何响应，不能将 5% 拉伸称为实测应力。
