# M03 四层方布输入

原生 DexSim 预览入口为 `physics/platforms/dexuni/dexsim/m03.py`。
配置使用 W1 V030 / 双 Pika，四张独立 300×300 mm、18 g 方布，
31×31 节点/层；材料、层间初始间距、夹指开口和阶段时刻均显式保存。
机器人根部沿 +X 靠桌 80 mm，并同步变换离线 IK 与 Scene 根位姿，让远边
落点处于可达范围；铺放段按完整 300 mm 布长展开，减少中段堆折。

`one_way`、运动学回放、`surface-fast`、CUDA Graph；基础迭代数由 preset
设置，保留其加速机制和自适应回退。使用包含弯曲的默认着色，保留弯曲及
层间/自接触。rest-shape 排除半径为 0，避免把初始靠近的独立布层过滤掉。
粒子对刚体半径 3 mm、自接触半径/裕量 2 mm、初始层间距 6 mm 分别登记，
不能把它们统称为物理布厚。

取料支撑与目标支撑同高；取料端有两个 80 mm 下指通道。为减少抖动、
改善先落桌的远边，当前预览使用 23.5 s 慢速轨迹：横移时保持高度，停稳
后垂直落远边，短暂停留后铺回近边，张口并水平退出下指，再抬手。
当前阻尼是场景调试参数，不是已完成材料标定。

生成的机器人快照、四层网格、命名关节轨迹、实际状态和视频统一保存在
`outputs/benchmarks/tech_reports/dexuni/m03_four_layer_cloth_pick_place/`；这里不存放生成二进制。
原生视频已获用户确认。EmbodiChain / Isaac Lab 的完整 M03 视频已完成，等待并排视频审阅；两边保留此处冻结输入，EC 为 surface-fast，IL 为普通 VBD20。正式性能测量尚未开始。
