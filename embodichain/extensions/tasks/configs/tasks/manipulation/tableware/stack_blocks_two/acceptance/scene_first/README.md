# Conditional scene-first task fixture

This deployment keeps the task's declared controller, physical acceptance and
confirmed persistence gates while comparing bounded versus scene-first XY layouts.
`expansion.yaml` owns explicit support parents, sampling ranges, the task phase
graph and screening effort. It does not change the ordinary deployment defaults.

See the [cross-task acceptance guide](../../../../../../../../../../scripts/benchmark/expansion/README.scene_first.md) for commands, conditional
anchor semantics, scope restrictions and result interpretation.
