# PolaRiS Organize Tools

A DROID Franka Panda with a Robotiq 2F-85 operates in the original organize tools capture by Arhan Jain and the PolaRiS team. The instruction is “put the scissor into the large container”. [Source capture](https://huggingface.co/datasets/owhan/PolaRiS-Hub/tree/8c7e4103e266ef83d8b1ad2e9a63116edd5f155b/organize_tools)

The scene contains `container_00`, `container_01`, `scissor`, `tape`. Reach the scissors, lift them more than 4 cm off the table and release them over the large container (container_00).

The [shared environment guide](../README.md) covers the physical scoring thresholds, action and camera contracts, evaluation entry point, and differences from the published setup.
