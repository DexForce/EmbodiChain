# PolaRiS Tape Into Container

A DROID Franka Panda with a Robotiq 2F-85 operates in the original tape into container capture by Arhan Jain and the PolaRiS team. The instruction is “put the tape into the container”. [Source capture](https://huggingface.co/datasets/owhan/PolaRiS-Hub/tree/8c7e4103e266ef83d8b1ad2e9a63116edd5f155b/tape_into_container)

The scene contains `container_02`, `tape_00`, `wrench`. Reach the tape, lift it more than 4 cm off the table and release it over the container (container_02).
