# RP Hand asset provenance

`RoboPartyRPHand` shares the `RoboPartyRP1` cache and derives the standalone
left and right URDFs from the articulated model. It removes each incoming
wrist mount and retains the hand's links, joint names, inertials, mimic
relationships and source meshes. The pinned description repository leaves
asset license terms unspecified. These assets are fetched from their upstream
source on demand. [Pinned RoboParty source](https://github.com/Roboparty/rp1_description/tree/7b7d807e52cbec23f22f36444ed3129f082d76ca)
