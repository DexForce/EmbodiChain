# LeWM research notes

The supported user workflow is the [Cube showcase](../cube/README.md). The
[historical UR push-cube workflow](PUSH_CUBE.md) retains the existing offline
supervised-training, reachable-goal and candidate-ranking commands.

The earlier Default/PhysX Cube migration recorded controller, constraint and
contact comparisons, including the 34/50 official MuJoCo result. The complete
[October 31 research checkpoint](https://github.com/DexForce/EmbodiChain/tree/1d120abf6578ab38fe8f226e607f0a3bdf6c81ed/examples/learning/lewm/validation/paused-2026-10-31)
contains the experimental scripts, reports and provider-specific work. The
current example uses the DexUni CPU rigid-body path with EmbodiChain RGB for
both goal images and online observations.
