# Evidence packaging

Main report inputs preserve original measured bytes under `main/`, including initial contracts, process records and supervisor training launches required by the fairness gates. Re-render with `python -m examples.ods.data_stream_demo.training_report MAIN_PATH --output SCRATCH_PATH`. All 30 outcomes remain present.

Original text/JSON/event/resource/context logs and earlier failed/development/smoke/wait/calibration attempts are stored in `raw-logs.tar.gz`; `raw-log-files.json` records every member's original SHA256. Extract to a separate scratch directory for independent event reconstruction. For log-only re-audit without the external GB checkpoints, use this script with --mode audit --skip-checkpoints --formal SCRATCH/formal --protocol protocol.json; the new audit explicitly records checkpoint verification as not requested. No success or slow run is selected away.

Datasets and checkpoints remain at the exact absolute paths in `external-artifacts.json`, with file hashes. They are not included as GB binaries. Copies or loss of those local paths affect artifact availability, not the preserved measurements. `comparison.json` is compact; full per-run data remain in `main/summary.json` files. The redundant generated giant report.json is reproducible rather than duplicated here. The full suite-summary.json, which embeds that same report again, is retained once in the compressed raw archive; main/suite-overview.json is an explicitly derived compact overview.

`independent-audit.json` reconstructs completed-work source/frame/state diversity and checks replay manifests. Checkpoint verification uses CPU. Final-model equality and encoded-video-file parity are separately labeled diagnostics; no full raw-RGB identity is asserted. Post-timing SDK audit and 20-state evaluation do not contribute to pipeline time. The original numeric/H2 SDK audit covers each source plus fixed RGB references. New formal qualification also requires the separately revisioned full-video-integrity/v1 receipt: every saved AV1 frame is sequentially software-decoded to YUV420p with source/frame counts and compressed/metadata hashes checked. This is not lossless RGB fidelity or exhaustive SDK seek certification. Both receipt types are retained distinctly and both validations are outside pipeline time.

Human interpretation and final experiment conclusions are owned by the study README, not generated by this packaging tool.

The exact 29 protocol-listed source files are also preserved under `frozen-source/`, with their SHA256 source manifest and frozen implementation commit. This snapshot precedes any post-study shutdown fix; it is a provenance snapshot, not a complete replacement installation of the repository.
