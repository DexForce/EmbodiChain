Task Deployments
================

This index uses the official task catalog and configuration files from this
documentation version. Rows identify deployment names, environment IDs, and
capabilities declared in those files. A dash indicates that the static catalog
did not resolve one backend for that deployment.

Use ``embodichain show-task embodichain.extensions.tasks:<task-key>`` to get the
launch command and validation records for an installed task. See the
:doc:`/guides/task_catalog` for runtime discovery and gallery export.
