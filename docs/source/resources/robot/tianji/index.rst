Tianji
======

Official Tianji robot configurations live in the
``embodichain_robots.tianji`` manufacturer namespace.

.. list-table::
   :class: robot-catalog
   :header-rows: 1
   :widths: 24 25 51

   * - Robot
     - Configuration class
     - Current coverage
   * - :doc:`Tianji Marvin <marvin>`
     - ``TianjiMarvinCfg``
     - Dual 7-DOF arms with optional parallel-jaw grippers.
   * - :doc:`Marvin with Robotiq 2F-140 <marvin>`
     - ``TianjiMarvinRobotiq140Cfg``
     - Complete bare body with two fixed, explicitly calibrated Robotiq hands.
