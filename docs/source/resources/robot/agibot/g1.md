# AgiBot G1

`AgibotG1` loads AgiBot's original GenieSim `G1_120s` USD using the Default
(PhysX) backend with DexSim 0.6.0rc1. The model preserves the source's fixed
base, six mimic relationships and four spherical gripper closures. Declare the
robot before preparing the simulation.

```bash
embodichain data download --name AgibotG1
embodichain preview-robot --robot AgibotG1 --physics default
```

The preset resolves 20 commanded joints across `torso`, `head`, `left_arm`,
`right_arm`, `left_eef` and `right_eef`. Each gripper group commands the outer
driver joint. The preset provides joint-space control. Its passive joints follow
the original mechanism.

To supply a local copy, use the complete original directory and its referenced
layers.

```python
from embodichain.robot_registry import resolve_robot_cfg

cfg = resolve_robot_cfg(
    "AgibotG1",
    {"source": {"file_path": "/path/to/G1_120s/robot.usda", "source_prim_path": "/G1"}},
)
robot = sim.add_robot(cfg)
sim.prepare()
```
