# Models

EmbodiChain bundles its model families in `embodichain.extensions.models`.
Choose a policy to generate actions from observations and goals. Choose a
dynamics model to predict the next robot state, visual embedding, or geometry.
Each guide links to its runnable workflow. For the launcher syntax and a
list of installed examples, see the [examples guide](https://github.com/DexForce/EmbodiChain/tree/main/examples).
