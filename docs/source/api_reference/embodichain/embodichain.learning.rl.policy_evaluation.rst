EmbodiChain Viewer Bridge
-------------------------

Tasks opt into planar camera tracking with ``PolicyViewerCameraCfg`` and a
world-pose provider. The preset controls reset framing; step updates preserve
manual orbit and zoom while following the target in X-Y.
