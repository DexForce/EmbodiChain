FEP configuration-search IK
===========================

Numerical inverse kinematics for seven-revolute-joint chains. The solver
supports seeded correction, sign-constrained configurations, eight-branch
enumeration and outward seventh-joint seed search. See
:doc:`../overview/sim/motion/solvers/fep_solver` for shapes and examples.
