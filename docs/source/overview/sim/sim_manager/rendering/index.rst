Rendering
=================================

This section documents EmbodiChain's rendering configuration and the advanced
features provided by the DexSim renderer. The simulation manager owns the
rendering lifecycle, while these pages describe renderer selection, image
quality, DLSS, and related performance trade-offs.

Start with :doc:`configuration` for common ``RenderCfg`` options. Use
:doc:`dlss` for NVIDIA DLSS behavior and temporal-rendering settings.
Use :doc:`materials` for default material presets, parameters and OfflineRT galleries.
