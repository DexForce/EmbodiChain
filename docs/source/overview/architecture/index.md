# Architecture Explorer

Explore EmbodiChain through a system overview and a detailed Task Program view.
Select a module to inspect its responsibility, follow direct relationships, and
read the source evidence behind each connection. Source links identify the exact
commit being documented; documentation links stay within this documentation version.

The graph describes selected static relationships. It is not a runtime trace,
an execution sequence, or a complete dependency inventory. Reviewed semantic
relationships and extracted import declarations are labeled separately.
