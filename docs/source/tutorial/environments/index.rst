Environments and Data
=====================

For a new Gym environment, start with the first two tutorials to learn the Gym
interface and modular ``EmbodiedEnv`` configuration. For Task Program, choose
the tutorial that matches your setup.

* :doc:`Modify an existing task </overview/task_program/quickstart>` to edit a
  program, run it, and save one expert trajectory.
* :doc:`Integrate a new scene or robot <../task_program>` to configure the
  environment, embodiment, and execution policy.
