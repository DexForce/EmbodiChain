Tutorials
=========

These tutorials walk through EmbodiChain from simulation fundamentals to task
authoring, environment workflows, and learning. Code-oriented tutorials include
runnable scripts; deployment tutorials include complete configuration examples.

Suggested learning path
-----------------------

Work through the categories in order when you are new to EmbodiChain:

1. :doc:`simulation/index` — create scenes, control robots, use Atomic Skills,
   and author a Task Program in Python.
2. :doc:`environments/index` — build Gym environments, deploy a configured Task
   Program, and generate demonstration data.
3. :doc:`learning/index` — train reinforcement-learning policies.

To add a new robot after completing the core tutorials, continue with
:doc:`/guides/add_robot`.
