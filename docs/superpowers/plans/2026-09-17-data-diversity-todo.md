## 6. 恢复开发时建议的顺序

1. 先收敛当前可用版本：切片恢复、关节/时间契约、阶段回放联动，以及媒体对账。
2. 再扩大接入：通用仿真实际事件、真实多父血缘、历史/真机数据样本。
3. 随规模补分页、媒体按需读取、增量缓存与新性能基准。
4. 用户重新确定范围后，按 D1 → D2 → D3 推进扩增闭环，再进入 D4 → D5。

每一轮只认领明确的 TODO 子项，提前约定验收样本和判据；交付后更新本文状态并链接新报告，不回写历史报告来扩大过去的完成范围。
