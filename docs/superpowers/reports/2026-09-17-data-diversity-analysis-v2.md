1. 在“分布分析”中设置类别多选、数值上下界或数据可用性，再应用筛选。
2. 查看逐维定义、单位、来源和完整度，切换单维分布或三种联合分布。
3. 点击联合分布表的一行，收窄到该单元格的 episode；导出当前切片可核对 ID 和分箱边界。

## 本轮验收

| 范围 | 结果和边界 |
|---|---|
| 维度定义 | 资产、姿态、Affordance、轨迹、材质、光照六类，共 11 个标量字段，定义版本为 1；分别统计已知、未知、缺失和不兼容值及来源。错误单位标为不兼容，不自动转换。 |
| 筛选 | 5 个类别多选，XYZ / yaw / 光照 / 时长 6 个数值范围，以及可用性筛选。反向范围和非有限值被拒绝；数值 0 不作为缺失。 |
| 联合分布 | 资产 × X 分箱、Affordance × 接近方式、材质 × 光照。分箱采用左闭右开、最后一箱右闭，保留越界和未知记录。位置分箱在同一状态范围的筛选间保持一致。 |
| 下钻和导出 | 单元格保存精确 episode ID；选择后总览、图表、列表与导出使用同一个已应用数据集。导出包含维度版本、分箱、筛选及下钻历史。 |
| 阶段对齐 | 按任务阶段名称和出现次序匹配，支持整条轨迹。缺少匹配阶段、非法边界或不兼容机器人/关节维数明确报错。 |
| 时间和几何 | 曲线横轴按阶段时间归一化；时长和速度使用原始记录时间。几何距离以弧长重采样计算，合成测试验证同一路径改变速度后距离为 0，弯曲路径距离非零。 |
| 曲线 | 展示 TCP XYZ、TCP 速度、关节原始值。没有关节名称/单位元数据时使用索引标签，不假设所有关节都是角度。 |
